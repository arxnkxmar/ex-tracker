#  Simple Expense Tracker  
A clean and lightweight **Expense Tracker Web App** that helps users record daily spending and calculate the total amount in real-time.

Perfect for beginners learning **HTML, CSS, and JavaScript**.

---

## 🚀 Features

- Add expenses with a name & amount  
- Automatically updates total balance  
- Minimal & modern UI  
- Fast and responsive  
- Beginner-friendly code  

---

## 🛠 Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

No frameworks or backend required.
